# SWTOR GTN Data Pipeline Test

Test website for verifying the complete data flow:

```text
Game Client
    ↓
GTN Data Collection
    ↓
Json Raw Data
    ↓
Craft Price Analyzer
    ↓
Json Result Data
    ↓
Git Deployment
    ↓
HTML Visualization
```

## Video

This web interface extends the functionality of the SWTOR GTN Analyzer mod.

https://www.youtube.com/watch?v=Pylq4YGcSuw

The goal is to test the full pipeline from SWTOR GTN data collection to web visualization.
